## 🚀 Key Features
- 🛍️ **Product Catalog:** Dynamic product filtering and categorization.
- 🛒 **Interactive Cart:** Real-time item management and checkout workflow.
- 🔐 **User Accounts:** Secure Auth integration powered by Supabase.
- 📱 **Mobile First:** Fully responsive layout across all screen sizes.

## 📦 Main Dependencies
- `next`
- `react` / `react-dom`
- `@supabase/supabase-js`
- `tailwindcss`
